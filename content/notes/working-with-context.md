I've been following [Eduardo Ferro Aldama](https://www.linkedin.com/in/eferro/)'s explorations about augmented coding [Cursor commands added to augmentedcode-configuration](https://www.eferro.net/2025/11/cursor-commands-added-to-augmentedcode.html)

Those sent me down a deeper path: how to reduce AI hallucinations and keep coding sessions genuinely productive, not just fast. One piece that really clicked was “Tu CLAUDE.md no funciona (sin Context Engineering)”:
[Tu CLAUDE.md no funciona (sin Context Engineering)](https://nikeyes.github.io/tu-claude-md-no-funciona-sin-context-engineering-es/)

From there, I got to the Frequent Intentional Compaction (FIC) framework, and this implementation as a Claude plugin: [stepwise-dev](https://github.com/nikeyes/stepwise-dev)

So, I decided to get my hands dirty and cloned Edu’s augmented coding tools repo: [my augmentedcode-configuration fork](https://github.com/saski/augmentedcode-configuration)
…adding a translation of the FIC Claude plugin, wiring it up as Cursor commands.

Still experimenting, but chasing the idea of explicit, repeated compaction of intent and context feels like gaining control when using these tools for coding. Less magic, more discipline.
