Less magic, more discipline: working with context

By Nacho Viejo · Originally published on LinkedIn
Web edition updated 6 Oct 2026

I've been following Eduardo Ferro Aldama's explorations about augmented coding Cursor commands added to augmentedcode-configuration

Those sent me down a deeper path: how to reduce AI hallucinations and keep coding sessions genuinely productive, not just fast. One piece that really clicked was “Tu CLAUDE.md no funciona (sin Context Engineering)”: Tu CLAUDE.md no funciona (sin Context Engineering)

From there, I got to the Frequent Intentional Compaction (FIC) framework, and this implementation as a Claude plugin: stepwise-dev

So, I decided to get my hands dirty and cloned Edu’s augmented coding tools repo: my augmentedcode-configuration fork …adding a translation of the FIC Claude plugin, wiring it up as Cursor commands.

Still experimenting, but chasing the idea of explicit, repeated compaction of intent and context feels like gaining control when using these tools for coding. Less magic, more discipline.

An early experiment from December 2025. The configuration later evolved into Arnesto.
